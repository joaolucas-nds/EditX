## 🎓 Aprendizados / armadilhas

- `npx eslint --version` mostrando a versão nova não é prova de que o upgrade é seguro —
  só confirma o binário instalado naquele momento. O teste real é instalar mais alguma
  coisa (ou reinstalar do zero) e ver se os peer dependencies resolvem sem conflito. Isso
  já virou armadilha em CONTEXT.md.
- Tabelas de versão em documentação ficam desatualizadas com o tempo, mesmo sem ninguém
  errar nada — é esperado, não é um sinal de documentação malfeita. O hábito certo é
  sempre conferir `npm list`/`package.json` reais antes de confiar num número escrito.
- `npm audit` vai sempre mostrar vulnerabilidades em projetos que usam `fabric.js`
  (via `canvas`/`jsdom` opcionais) — não é sinal de projeto inseguro, é ruído esperado
  que vale documentar uma vez para não reinvestigar a cada sessão.

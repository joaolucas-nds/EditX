## ⚖️ Decisões tomadas

- **Fabric.js sobre Konva.js:** API de texto e serialização mais madura; Konva tem melhor binding React mas menos recursos para o tipo de editor necessário
- **Tauri sobre Electron:** bundle 15× menor, sem Chromium embutido, Rust no backend é mais seguro
- **Motor de overflow de texto customizado:** não existe biblioteca que implemente os 4 modos necessários (grow-vertical, grow-horizontal, fixed-shrink, fixed-clip) — implementação própria é obrigatória
- **`TemplateSchema.ts` implementado primeiro:** é o contrato entre todos os módulos; implementar o canvas antes dos tipos cria inconsistências difíceis de corrigir
- **Imagens por referência de caminho + opção "empacotar":** `.editx` leve e versionável por padrão
- **pdf-lib sobre jsPDF:** API TypeScript moderna, suporte a links internos, PDF/X futuro
- **BatchGenerator em Web Worker:** UI não pode travar durante geração de 500+ itens
- **Formato `.editx`:** JSON com extensão proprietária para identidade do produto

## 💡 Ideias capturadas

**Do usuário:**
- Editor visual estilo Canva/Figma especializado para materiais de varejo/food service
- Frames de texto populáveis via CSV com comportamento configurável ao atingir bordas (como Figma)
- Sistema de estilos de texto globais que atualiza todos os frames vinculados (como Word/Affinity)
- Suporte a menus dobráveis: C-fold e Z-fold
- População de imagens em massa via nome de arquivo no CSV
- Templates reutilizáveis para atualizar peças já produzidas
- App que funcione no navegador E como desktop

**Sugestões geradas:**
- `outputNaming` com variáveis do CSV para nomear arquivos do lote (`"{nome}-{preco}"` → `"coca-cola-5,99.pdf"`)
- `skipRowsWhere` para filtrar linhas do CSV diretamente no template (ex: `ativo = "sim"`)
- `isDataPage: true` nas páginas do template para catálogos multipáginas
- Formatadores nativos de coluna CSV: `currency:BRL`, `date:DD/MM/YYYY`, `uppercase`
- `fallback` em frames de imagem para quando o arquivo não for encontrado
- Modo "empacotar tudo" no `.editx` (base64) para compartilhamento sem pasta de imagens
- Biblioteca de templates pré-prontos como visão de longo prazo

## ⚠️ Atenção para próxima sessão

- **Fabric.js v6 quebrou compatibilidade com v5 na serialização** — não seguir tutoriais que mostram a estrutura `toJSON()` da v5. Consultar sempre a documentação oficial da v6.
- **`ctx.measureText()` não retorna altura real** — para métricas verticais de texto no `FrameText.ts`, usar `opentype.js` para calcular ascender + descender. Não depender de `actualBoundingBoxAscent` isoladamente.
- **`OffscreenCanvas` tem suporte limitado no Safari** — verificar compatibilidade antes de finalizar o `BatchGenerator.ts` em Web Worker. Pode ser necessário fallback para thread principal em Safari.
- **`TemplateSchema.ts` deve ser implementado antes de qualquer módulo do canvas** — a tentação de "começar pelo canvas que é mais visual" deve ser resistida.
